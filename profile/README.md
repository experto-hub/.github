## Mission

Turn engineering claims into evidence. We build focused, inspectable tools that make complex
systems easier to verify, reproduce, and operate with confidence.

## Public projects

| Project | Purpose |
| --- | --- |
| **[System Proof](https://github.com/experto-hub/system-proof)** | A typed Java framework for defining system-test topologies, running real components, and retaining evidence-backed diagnostics. |
| **[CI Images](https://github.com/experto-hub/ci-images)** | Narrow, contract-tested CI toolchains for Node.js, Python, and Java. |

## How we work

- **Evidence over assumptions.** Important claims should be testable.
- **Explicit over magical.** Contracts, boundaries, and failure modes should be visible.
- **Reproducible over machine-specific.** The path to a result should work twice.
- **Small over sprawling.** Focused systems are easier to understand, review, and evolve.
